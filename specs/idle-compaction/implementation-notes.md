# Idle maintenance implementation notes

The daemon's `ActivityGuard` covers the whole Router request future and watcher `apply_batch` future. Dropping an aborted request drops the guard and updates the last activity clock. Status and watch-list probes do not begin activity. The embedding pool owns the same `Arc<Activity>` as the daemon: each queued job holds a lease from enqueue through model completion or abandonment, and warm-up holds a lease. A single packed atomic word changes active count and epoch together, so a quiet snapshot has one linearization point even when RPC and native work overlap. Count or epoch overflow poisons the word and disables maintenance rather than permitting epoch reuse. Model warmth is not used as an activity signal.

The idle monitor observes the single shared quiet epoch. It begins a quiet clock only after all owner leases are gone, resets that clock when the epoch changes, and runs at most one completed maintenance pass for that epoch. Zero `SS_IDLE_COMPACT_SECS` disables the pass. The blocking task rechecks the same quiet epoch at its start. New work arriving during a merge remains admitted and sees immutable cache snapshots. A cache candidate skipped because another compaction owns its flag remains pending, so the quiet epoch is retried on a later monitor tick. The pass logs `idle maintenance complete` with compacted and pending roots, the native allocator's returned byte hint, platform support, activity epoch and quiet milliseconds.

`vector_cache::compact_idle` selects only loaded lists with multiple segments or tombstones, uses each shard's existing compaction flag with a drop guard on both normal and idle paths, and reuses the immutable merge/swap primitive. Held readers retain their old `Arc<List>`. The macOS reclaimer calls the SDK `malloc_zone_pressure_relief(NULL, 0)` declaration from `malloc/malloc.h:518-524`; other platforms report an explicit unsupported result. Its returned bytes are an allocator hint, not process RSS.

The `idle_compaction_oracle_` fixture uses one pure row predicate for direct authored and actual merged lists, and rejects a missing row and wrong vector. Direct channel ownership and `rg --files` checks cover their independent live/closed and present/absent/empty controls. Two `idle_compaction_vectors_` fixtures inspect exact IDs/matrix values and held-reader lifetime from a directly installed immutable list, and verify a compact list is left intact. The direct list avoids racing the normal publish-triggered compactor. Two `idle_compaction_gate_` fixtures exercise actual maintenance attempts against overlapping owner/native model gates, once-per-epoch execution, zero disabled, and a foreground embedding admitted while a channel-held maintenance body runs.
